# UEPS visual

Instructivo interactivo para aprender el método contable UEPS, diseñado con especial atención a personas con dislexia y discalculia.

## Experiencia

- Nueve tarjetas breves con el ejercicio resuelto paso a paso.
- Navegación con botones Anterior y Siguiente.
- Índice glass para saltar a cualquier paso.
- Tabla acumulativa disponible desde cada tarjeta.
- Diseño responsive de una sola pantalla, sin scroll.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```
